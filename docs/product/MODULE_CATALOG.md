# Module catalogue

Modules compose one operational platform; a map or score alone is not a
module outcome. Each follows `asset -> data -> context -> rule -> decision ->
action -> result` and links to the feature catalogue for lifecycle status.

| Module | Problem / users | Inputs -> outputs | Relationship and limitation |
|---|---|---|---|
| Maps | Spatial understanding for operators/customers. | Verified geometry -> contextual layers. | Consumer of the Digital Twin; visual coverage is not evidence by itself. |
| Farm360 | Property-level operational view. | Assets, observations, events -> traceable context/report. | Shared shell for Agro, Flood, Connect and IoT; not a legal cadastre. |
| Prospect | Explainable qualification for commercial users. | Permitted context -> reviewable opportunity. | Need remains unconfirmed without evidence. |
| Connect | Connectivity consulting. | Assets/terrain/provider facts -> feasibility review. | Requires real inventory and engineering validation. |
| Agro / Soil Intelligence | Agricultural context for growers/consultants. | Terrain, remote, lab, field data -> preliminary/validated assessment. | Remote/modelled and measured evidence remain distinct. |
| Banana Intelligence | Banana-specific consulting workflow. | Verified field/crop evidence -> inspection/recommendation. | No disease diagnosis without approved expert policy. |
| IoT | Monitored physical assets. | Authenticated telemetry -> quality-controlled observations. | Vendor-neutral; no unauthenticated ingress. |
| Monitor | Alerts and operational follow-up. | Rules/evidence -> alert/action/result. | Cannot manufacture a decision from missing evidence. |
| Rules | Auditable decision logic. | Scoped inputs -> decision/recommended action. | Rule applicability/version and expert validation are explicit. |
| Trace | Auditability. | Source-to-outcome links -> reconstructable history. | Supply-chain trace is later. |
| Energy | Energy asset context/risk. | Confirmed inventory/measurements -> rule context. | Provider/asset contracts still required. |
| Security | Privacy, RLS and access control. | Identity/policy -> authorized operation. | Cross-cutting and mandatory, not an optional add-on. |
| Business | Catalogue, contracts, capacity and commercial evidence. | Policies/evidence -> governed service/opportunity. | Opportunity is not confirmed demand. |
| Flood / Environmental Intelligence | Event risk for operators, growers and prospects. | Facts/hypotheses/exposure -> reviewable action. | Causality and flood extent require explicit support. |
| AI | Grounded assistance. | Governed context -> cited assistance. | Deferred until evaluation, permissions and safety gates exist. |
