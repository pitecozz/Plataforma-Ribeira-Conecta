# Service catalogue

This catalogue describes service **hypotheses**, not a promise, finalized
package or final price. A service becomes commercially available only after
capacity, provider terms, expert requirements, cost and customer validation.

| Service | Intended value | Delivery boundary | Status |
|---|---|---|---|
| Farm360 baseline | Property map, Digital Twin context and periodic summary. | Requires confirmed property/onboarding; excludes legal surveying. | `TO_VALIDATE` |
| Flood/environmental risk report | Traceable event/exposure context and unknowns. | Requires verified inputs; not a loss, causal or insurance conclusion. | `TO_VALIDATE` |
| Connectivity assessment | Contextual feasibility study. | Requires inventory/field engineering; no assumed service availability. | `TO_VALIDATE` |
| Preliminary agricultural suitability | Explainable initial assessment and missing-evidence plan. | Not validated suitability or planting guarantee. | `PLANNED` |
| Banana Suitability assessment | Crop-specific review with expert process. | Agronomic policy/inspection may be required. | `PLANNED` |
| Smart soil sampling plan | Derived management zones and suggested points. | Points require technician confirmation and lab chain. | `PLANNED` |
| Sensor deployment design | Need-driven telemetry design. | Hardware/connectivity/install are separate costs/services. | `PLANNED` |
| Laboratory integration | Traceable import and contextual interpretation. | Does not replace laboratory/agronomist responsibility. | `PLANNED` |
| Drone / field inspection | Localized validation or anomaly review. | Third-party/device/field safety scope is separate. | `RESEARCH` |
| Custom integration/report | Customer-specific evidence workflow. | Scope, data terms, security and cost must be agreed. | `TO_VALIDATE` |

Commercial opportunities must preserve `evidence -> need/opportunity ->
applicable service`. Missing data is not a sales lead.
